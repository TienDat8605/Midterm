# DINO PARK: Sticky Summit

Sticky Summit is a 2D vertical platformer developed in Unity. Players charge and release jumps to climb a dangerous mountain, avoid traps and enemies, and rescue a missing daughter at the summit. The game supports single-player testing and three-player online cooperation through Photon PUN 2.

## Game and Applications

- **Single Player:** select a slime role and climb the map locally.
- **Online Multiplayer:** create or join a private three-player Photon room with a six-character code.
- **Three cooperative roles:** Anchor becomes a stable stone, Bounce launches teammates, and Sticky pulls or rescues allies with a tether.
- **Physics platforming:** grounded movement, charged jumps, no air steering, wall bonking, springs, vortex traps, and knockback enemies.
- **Supporting systems:** character and map selection, camera follow, vertical progress display, audio, pause/end-game flow, procedural map tools, and desktop/WebGL display handling.
- **Tutorial:** introduces the controls, objective, and cooperative roles.

## Unity Version

- **Unity:** 6000.3.16f1
- **Render pipeline:** Universal Render Pipeline 2D
- **Input:** Unity Input System
- **Networking:** Photon Unity Networking 2 (PUN 2)

## Open the Project

1. Open Unity Hub.
2. Add this repository as a project.
3. Open it with Unity `6000.3.16f1`.
4. Open `Assets/Scenes/Main.unity` and press Play.
